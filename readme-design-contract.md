# README Design Contract
## readmeArchetype
Radio repair transcript.
## readmeNarrativeVoice
Calm late-night bench technician.
## readmeSectionPattern
Call sign, symptom signal, bench interlocks, diagnostic relay, tuning commands, sign-off.
## readmeMotif
Annotated service call sheet.
## requiredFactsPlacement
Call sign carries identity and links; symptom signal maps state; interlocks explain guards; relay covers consensus and methods; tuning commands cover build and tests; sign-off states limits.
## bannedReadmePatterns
No film slate, kitchen ledger, mural permit, journey pass, or generic product manual.
## proofOfDifference
This reads like a live radio service transcript and starts with a call sign, unlike the previous editing report.
